## ✨ Características Destacadas

Este proyecto fue construido con un enfoque estricto en las mejores prácticas de desarrollo Frontend:

- **Maquetación Semántica:** Uso correcto de etiquetas HTML5 (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`) para mejorar la accesibilidad y el SEO.
- **Arquitectura CSS:** Estilos puros y organizados sin depender de frameworks externos (como Bootstrap o Tailwind).
- **Diseño Responsivo (Mobile First):** La interfaz se adapta perfectamente a dispositivos móviles, tablets y monitores de escritorio utilizando Media Queries.
- **Layouts Modernos:** Implementación intensiva de **CSS Flexbox** (y/o CSS Grid) para alinear y distribuir los elementos complejos (como el header y la cuadrícula de modelos).
- **Tipografía y Rendimiento:** Integración optimizada de Google Fonts (Raleway) e imágenes preparadas para la web.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5** (Estructura semántica y accesible)
- **CSS3** (Variables nativas, animaciones, Flexbox/Grid)
- **Normalize.css** (Para consistencia entre distintos navegadores)
